# Changelog

All notable changes to **Neon Platformer** are documented here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [1.0.0] — 2026-06-07

### 🎉 Initial Release

#### Added
- Full 2-level boss-rush platformer
- 3 playable characters with distinct weapons:
  - `isleepinmorning` — Pistol (balanced)
  - `hakomsad` — Long Gun (high damage, slow fire)
  - `baunabadmaash` — Flamethrower (continuous DPS)
- Boss 1: `devesh high cortisol` — erratic rush AI with random jumps
- Boss 2: `kevin` — ghost AI with invisibility, teleport, and instant-strike mechanic
- Particle explosion system with per-color neon glows
- AABB platformer physics with per-axis collision resolution
- Player invincibility frames (40 ticks after hit)
- Live HP bars for player and boss
- Pulsing cyberpunk neon aesthetic with canvas shadow glows
- Full keyboard controls + mouse click shooting
- Character switcher (P key) mid-run
- Game over / win screens with restart (R key)
- GitHub Pages auto-deploy workflow
- Zero dependencies — single HTML file
